# Empirial Study Board

Responsive study-abroad landing page built with React and Vite.

The UI is styled with Tailwind CSS utility classes. Page sections live in
`src/components/`, and repeated study-abroad content is kept in
`src/data/studyAbroad.js`. `src/tailwind.css` is the minimal Tailwind v4 entry
point used to load the framework and theme tokens.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```sh
npm install
npm run dev
```

Vite prints a local URL after starting the development server.

## Production build

```sh
npm run build
npm run preview
```
